# AI Agent入门

## Agent = LLM + 上下文 + 工具

我们将Agent看作一个人的话，**LLM**就是大脑（负责决策和思考），**上下文**就是眼睛（接受环境提供的观察），**工具**就是手脚（将决策转化为作用于环境的行动）。

**Agent = 大脑 + 眼睛 + 手脚**

**LLM**：大语言模型（**Large Language Model**）。LLM是Agent的**决策内核**，就像人脑一样起到一个**理解意图、思考规划、做出判断**的作用。其能力来自**预训练**积累的世界知识与语言能力，及**后训练**（监督微调与强化学习等技术）固化的决策策略。

**上下文**：Agent在每个决策点收到并保留的**信息表示**（包括**来自环境的观察、用户记忆、领域知识、自身状态和任务进展**）。

**工具**：Agent感知或改变世界的**接口**，包括**工具定义、调用协议和适配器**。

```markdown
- 环境状态也可以被读取、筛选并编码进上下文，上下文≠环境。
- 工具背后的文件系统、数据库、网页、用户或物理世界也仍属于环境。
```
